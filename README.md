# Louisiana Records Retention Schedules
This is a repository of records retention schedules maintained by state and local government agencies in Louisiana.

Records retention schedules are lists of records kept by an agency that specify how long records must be kept on hand before they are disposed or archived. These schedules can be useful for identifying forms to target with public records requests.

In Louisiana, government agencies are required [under state law](https://www.legis.la.gov/Legis/Law.aspx?d=99732) to submit records retention schedules to the state archivist in the Secretary of State's office for approval (and renewal every five years thereafter). That process is [outlined here](https://www.sos.la.gov/archives/retention-schedules). By default, records not covered by a formal retention schedule must be kept for a minimum of three years.

All of the schedules in this repository were obtained via public records requests to the applicable agency.
